# Perbaikan Tampilan Katalog — Compact Quick Order

Perubahan:
- Katalog mobile dibuat 2 kolom agar lebih banyak item terlihat sekaligus.
- Foto item diperkecil agar tidak menghabiskan layar.
- Padding, judul, deskripsi, harga, varian, dan kontrol jumlah dibuat lebih ringkas.
- Tombol kategori tetap berada langsung di katalog dan bisa digeser horizontal.
- Tombol + Tambah tetap tersedia sehingga pelanggan dapat menambahkan banyak item tanpa keluar-masuk halaman.
- Pada layar sangat kecil (<=390px), ukuran kartu diperkecil lagi.

Tidak ada perubahan database/SQL untuk patch tampilan ini.
