# AOC V54 — Private Trip mengikuti struktur Open Trip

Private Trip dibuat terpisah dari Travel, tetapi struktur paketnya disamakan dengan Open Trip.

## Private Trip tidak memakai
- Transportasi
- Akomodasi
- Driver
- Nomor kendaraan
- Jadwal hari mingguan

## Private Trip memakai
- Nama paket
- Asal dan tujuan
- Kapasitas maksimal dalam orang
- Minimal peserta
- Usia minimum/maksimum
- Titik meeting dan petunjuk meeting
- Tingkat kesulitan
- Harga per paket (bukan per orang)
- Itinerary
- Include / termasuk
- Exclude / tidak termasuk
- Perlengkapan wajib
- Informasi untuk peserta
- Foto utama
- Status dan aktif/tidak aktif

Perubahan database juga sudah diterapkan pada project Supabase AOC.
