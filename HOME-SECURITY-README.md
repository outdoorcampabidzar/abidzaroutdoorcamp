# AOC Home Security Challenge

Beranda sekarang meminta kode keamanan 6 digit baru setiap kali halaman Beranda dibuka.

## Penting
Challenge ini adalah lapisan UX/anti-akses kasual. Ia BUKAN pengganti:
- Supabase Auth
- Row Level Security (RLS)
- PIN transaksi user
- verifikasi server-side untuk checkout/operasi sensitif

PIN transaksi user tetap berbeda dan digunakan untuk checkout sesuai sistem m-Banking AOC.
